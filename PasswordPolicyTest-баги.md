# Баг-репорты PasswordPolicy

## PP-1. Пароль длиной 64 символа определяется как слишком длинный

Окружение:

- проект: password-policy-testing
- пакет и тип: passwordpolicy.PasswordPolicy
- Go 1.26.1, macOS arm64

Шаги воспроизведения:

1. Создать `PasswordPolicy`
2. Проверить валидный пароль длиной 64 символа: `"He!1" + strings.Repeat("lo", 30)`
3. Получить найденные нарушения вызовом `result.Violations()`

Фактический результат: в списке есть `TOO_LONG`

Ожидаемый результат: `TOO_LONG` отсутствует. Согласно спецификации, «длина больше 64: TOO_LONG. Длина ровно 64 допустима»

Severity: Major. Валидный по спецификации пароль отклоняется

Priority: High. Ошибка находится в основной проверке допустимой длины

## PP-2. Серия из трех одинаковых символов не определяется как нарушение

Окружение:

- проект: password-policy-testing
- пакет и тип: passwordpolicy.PasswordPolicy
- Go 1.26.1, macOS arm64

Шаги воспроизведения:

1. Создать `PasswordPolicy`
2. Проверить пароль `He!1lllW`
3. Получить найденные нарушения вызовом `result.Violations()`

Фактический результат: `REPEATED_RUN` отсутствует, пароль считается валидным

Ожидаемый результат: в списке есть `REPEATED_RUN`. Согласно спецификации, «три и более одинаковых символа подряд: REPEATED_RUN. aaa является нарушением, aa не является»

Severity: Major. Пароль, нарушающий политику, принимается как валидный

Priority: High. Дефект ослабляет установленное правило проверки пароля

## PP-3. Проверка blacklist зависит от регистра

Окружение:

- проект: password-policy-testing
- пакет и тип: passwordpolicy.PasswordPolicy
- Go 1.26.1, macOS arm64

Шаги воспроизведения:

1. Создать `PasswordPolicy`
2. Проверить пароль `PaSsWoRd`
3. Получить найденные нарушения вызовом `result.Violations()`

Фактический результат: `BLACKLISTED` отсутствует

Ожидаемый результат: в списке есть `BLACKLISTED`. Согласно спецификации, «пароль совпадает с одним из простых: password, qwerty, 123456, admin, welcome, без учета регистра»

Severity: Minor. Список нарушений неполный, но такой пароль все равно отклоняется другими правилами

Priority: Medium. Правило blacklist работает неправильно, но итоговая валидность перечисленных простых паролей не меняется
