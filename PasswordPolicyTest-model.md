# Тестовая модель PasswordPolicy

Базовый валидный пароль: `He!1loW8`

## Границы

| Проверка      | Данные                   | Ожидание          |
|---------------|--------------------------|-------------------|
| Длина 7       | `He!1loW`                | `TooShort`        |
| Длина 8       | `He!1loW8`               | Пароль валиден    |
| Длина 64      | `He!1` + `lo` x 30       | Пароль валиден    |
| Длина 65      | `He!1` + `lo` x 30 + `W` | `TooLong`         |
| Повтор 2 раза | `He!1llWo`               | Нет `RepeatedRun` |
| Повтор 3 раза | `He!1lllW`               | `RepeatedRun`     |

## Остальные проверки

| Правило             | Класс                               | Данные                                   | Ожидание                                                 |
|---------------------|-------------------------------------|------------------------------------------|----------------------------------------------------------|
| Пароль не передан   | Невалидный                          | `nil`                                    | `ErrNilPassword`                                         |
| Пароль передан      | Валидный                            | `He!1loW8`                               | Ошибки нет                                               |
| Цифра               | Нет цифры                           | `He!aloWb`                               | `NoDigit`                                                |
| Цифра               | Есть цифра                          | `He!1loW8`                               | Нет `NoDigit`                                            |
| Заглавная буква     | Нет латинской заглавной             | `he!1lowo`                               | `NoUpper`                                                |
| Заглавная буква     | Есть только кириллическая заглавная | `Нe!1lowo`                               | `NoUpper`                                                |
| Заглавная буква     | Есть латинская заглавная            | `He!1loW8`                               | Нет `NoUpper`                                            |
| Строчная буква      | Нет латинской строчной              | `HE!1LOWO`                               | `NoLower`                                                |
| Строчная буква      | Есть только кириллическая строчная  | `Hя!1LOWO`                               | `NoLower`                                                |
| Строчная буква      | Есть латинская строчная             | `He!1loW8`                               | Нет `NoLower`                                            |
| Спецсимвол          | Нет разрешённого символа            | `He.1loW8`                               | `NoSpecial`                                              |
| Спецсимвол          | Есть разрешённый символ             | `He!1loW8`                               | Нет `NoSpecial`                                          |
| Спецсимвол          | Каждый символ из списка             | `He<символ>1loW8`                        | Нет `NoSpecial`                                          |
| Пробелы             | Нет пробельных символов             | `He!1loW8`                               | Нет `HasWhitespace`                                      |
| Пробелы             | Пробел, таб или перевод строки      | Табличный набор                          | `HasWhitespace`                                          |
| Повторы             | Серии нет                           | `He!1loW8`                               | Нет `RepeatedRun`                                        |
| Повторы             | Повтор 4 раза                       | `He!1llll`                               | `RepeatedRun`                                            |
| Логин               | Найден без учёта регистра           | пароль `He!1Ivan`, логин `iVaN`          | `ContainsLogin`                                          |
| Логин               | Не найден                           | пароль `He!1loW8`, логин `ivan`          | Нет `ContainsLogin`                                      |
| Логин               | Пустой                              | пароль `He!1loW8`, логин `""`            | Правило не применяется                                   |
| Логин               | Не передан                          | пароль `He!1loW8`, логин `nil`           | Правило не применяется                                   |
| Blacklist           | Точное совпадение                   | Все значения из списка                   | `Blacklisted`                                            |
| Blacklist           | Другой регистр                      | `PaSsWoRd`, `QwErTy`, `AdMiN`, `WeLcOmE` | `Blacklisted`                                            |
| Blacklist           | Нет точного совпадения              | `Passw0rd!`                              | Нет `Blacklisted`                                        |
| Несколько нарушений | Невалидный пароль                   | Пустая строка                            | `TooShort`, `NoDigit`, `NoUpper`, `NoLower`, `NoSpecial` |
